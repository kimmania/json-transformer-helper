# Web Transform Assistant

Standalone static web app for building json-transformer mappings visually.

## Features

- Visual mapping construction with dual-pane tree views
- Live output preview
- Guided wizard mode
- Free-form editing mode
- Compute function support
- Zero-server deployment

## Requirements

See `transform-assistant-requirements.md` for full feature specification.

## Development

Open `index.html` directly in a browser — no server needed.

## Build

No build step. Single HTML file with inline Preact and transform engine.
